# IT Student Resource Hub

A web platform for IT students to share, upload, and access academic study materials, notes, and previous year question papers.

## Tech Stack
- Frontend: HTML5, CSS3
- Backend: PHP
- Database: MySQL
- Server: XAMPP (Apache)

## Features
- User Registration & Authentication
- File Upload & Download (.pdf, .docx, .png)
- Search & Filter by Subject / Semester
- Admin / User Control to Manage Uploads
